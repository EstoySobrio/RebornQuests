# Descargo de responsabilidad — RebornQuests

RebornQuests es un mod **no oficial** para Minecraft 1.12.2 (Forge). Se distribuye **"tal cual"**,
sin garantía de ningún tipo, expresa o implícita, incluidas pero no limitadas a las garantías de
comerciabilidad, idoneidad para un propósito particular y no infracción. El uso es bajo tu propia
responsabilidad.

## Requisitos y compatibilidad

- Las misiones se leen de **Custom NPCs**.
- Los rangos y permisos se leen de **LuckPerms**. **LuckPerms es un requisito del sistema de
  permisos.** Puesto que LuckPerms es un plugin, el mod **requiere un servidor compatible con
  plugins y mods a la vez** (un servidor híbrido que ejecute plugins de Bukkit junto con mods de
  Forge) para aprovecharlo.
- En un cliente o servidor Forge puro, sin plugin de permisos, el acceso se resuelve con el
  operador (op) del servidor y el dueño del mundo local.
- El mod **solo lee** de LuckPerms y de Custom NPCs; nunca escribe ni modifica sus datos.

## Servidores probados

- El mod se ha **probado en Magma** (servidor híbrido de plugins + mods para Forge 1.12.2).
- **No se puede asegurar el funcionamiento en otros servidores híbridos** (Mohist u otros). Pueden
  funcionar, pero no están probados y no se garantiza su compatibilidad.
- Si encuentras algún error en **Mohist u otro** servidor, **repórtalo en los
  [issues](https://github.com/EstoySobrio/RebornQuests/issues) de este repositorio**, indicando el
  servidor y su versión, la versión del mod y el log del error.
